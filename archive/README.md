# Historical material

This directory preserves superseded instance-specific launchers, dated rental
reports, and the original MNIST template. It is excluded from installation,
source bundles, test discovery and linting. It is not an execution interface.

`MIGRATION.json` records each original path, destination and original SHA-256.
Archived commands describe their original environment and may reference paths
that moved. Use `docs/migration.md` and the current manuals for execution.
Existing datasets, checkpoint files, credentials, and logs were not moved.
