## Anchor behavior and objective scope

Select the highest raw COMET complete nonempty generated candidate per source;
sample order breaks ties. Require direct source–candidate SAC Full match and the
declared eligibility screen. An unverified winner is not replaced by a lower
COMET candidate or a dataset reference. Unsupported groups are quarantined;
a consecutive-skip limit bounds attempts without optimizer progress.

Verified anchors teach rejected candidates through the implemented noise-aware
preference and likelihood losses. Fully eligible groups retain the existing
fixed-scale/dead-band ranking branch. Numeric scalar settings remain uncalibrated
ablation controls. Candidate texts, COMET scores, direct SAC, selected index,
cap status and eligibility are recorded in
`diagnostics/comet_anchor_candidates.jsonl` on the rental.

This run uses the implemented COMET/SAC correction objective. The proposed MQM
token-vector objective and new retention/gradient-projection scheme are **not
implemented or claimed as part of this run**. COMET selection follows the user's
requested comparison and is not independent human quality validation.
