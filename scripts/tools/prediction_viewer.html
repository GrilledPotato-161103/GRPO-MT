Review for meaning

Compare the prediction with the source first. The reference is one valid rendering; different wording can still be correct.

1 · Incorrect — Meaning lost or mostly wrong.
2 · Major errors — Substantial omissions or mistranslations.
3 · Usable — Main meaning preserved, some errors.
4 · Good — Accurate with minor wording issues.
5 · Excellent — Accurate, natural and complete.

COMET, SAC and reward are the values recorded in your CSV. They are model metrics, not human ratings. The optional word diff is a literal comparison with the reference, not an error detector.

Shortcuts outside text fields: ← / → previous / next; 1–5 rate; F flag; N next unreviewed. Export includes every example and its original metrics. Import accepts JSON exports from this exact dataset and merges matching example IDs.
